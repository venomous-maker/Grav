# Xml

`import "std/data"` (included in `import "std"`) · namespace `std.data`

XML read into a tree of elements and text (`XmlNode`), queried by paths of
child names (`find("entry/title")`, `*` for any), and written back out, for
feeds, sitemaps, SOAP and SAML replies and office files' XML parts. Entities and
character references are decoded and CDATA kept as text. A document with a DTD
(`<!DOCTYPE>`) is refused: DTDs are how XML entity attacks (XXE, "billion
laughs") get in. Names keep their namespace prefix; `localName()` drops it, and
`child`/`find` match either.

```grav
import "std"

fn main() {
    let feed = Xml.parse("<feed><entry id=\"1\"><title>Fish &amp; chips</title></entry><entry id=\"2\"><title>Tea</title></entry></feed>")
    for (e in feed.findAll("entry")) { print("${e.attr("id")}: ${e.find("title").text()}") }

    let map = XmlNode.element("urlset")
    map.add(XmlNode.element("url").add(XmlNode.element("loc").addText("https://example.com/?a=1&b=2")))
    print(map.toString())
}
```

Output:

```text
1: Fish & chips
2: Tea
<urlset><url><loc>https://example.com/?a=1&amp;b=2</loc></url></urlset>
```
