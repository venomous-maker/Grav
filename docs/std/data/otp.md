# One-time passwords

`import "std/data"` (included in `import "std"`) · namespace `std.data`

Two-factor codes: `Totp` (RFC 6238, time-based: what Google Authenticator,
1Password and Authy show) and `Hotp` (RFC 4226, counter-based). Secrets travel
as [Base32](encoding.md). Needs OpenSSL's libcrypto, as `Crypto` does.

```grav
import "std"

fn main() {
    let secret = Base32.encodeString("12345678901234567890")   // normally Totp.generateSecret()
    let totp = new Totp(secret)
    let at: long = 1111111109
    let code = totp.codeAt(at)
    print(code)
    print(totp.verifyAt(code, at))                     // the step it matched: store it
    print(totp.verifyAt(code, at, totp.stepAt(at)))    // the same code again: refused
    print(totp.uri("Acme", "ada@acme.test"))
    print(Hotp.code(Bytes.fromString("12345678901234567890"), 1))
}
```

Output:

```text
081804
37037036
-1
otpauth://totp/Acme:ada%40acme.test?secret=GEZDGNBVGY3TQOJQGEZDGNBVGY3TQOJQ&issuer=Acme&algorithm=SHA1&digits=6&period=30
287082
```

- **A secret** is `Totp.generateSecret()`: 20 random bytes (160 bits) in Base32.
  Show it once (or as the `uri` in a QR code) and store it encrypted.
- **`verify(code, lastStep, window)`** accepts a code from `window` steps either
  side of now (1 by default: a phone clock a little off still works) and only
  after `lastStep`. Store the step it returns, and each code works once. It gives
  -1 for a wrong code. Codes are compared in constant time.
- **Settings** per `Totp`: `digits` (6 to 10), `period` (30 seconds), and
  `algorithm` (`"sha1"`, which the apps assume; `"sha256"`, `"sha512"`).
- **`Hotp.verify(key, code, counter, lookAhead)`** returns the counter that
  matched; the server then stores the one after it.

### class Hotp

**Static members**

- `static fn code(key: Bytes, counter: long, digits: int = 6, algorithm: string = "sha1") -> string` — The code for `counter` under `key` ("sha1", "sha256" or "sha512"; 6 to 10 digits).
