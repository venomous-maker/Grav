# JSON Schema

`import "std/data"` (included in `import "std"`) · namespace `std.data`

Checking JSON against a [JSON Schema](https://json-schema.org) (the Draft
2020-12 keywords APIs use, and OpenAPI 3.0's `nullable`), and making a schema
from a class: the fields [JsonMap](json_map.md) reads.

```grav
import "std"

class Line {
    @Schema(min: 1, max: 99) public qty: int = 1
    public sku: string = ""
    constructor() {}
}

class Order {
    public id: long = 0
    @Schema(format: "email") public email: string = ""
    public note: string? = null
    public lines: Array<Line> = new Array<Line>()
    constructor() {}
}

fn main() {
    let schema = JsonSchema.compile(JsonSchema.forClass(reflect(Order)))
    let body = Json.parse("{\"id\": 7, \"email\": \"ada@\", \"lines\": [{\"qty\": 0, \"sku\": \"A1\"}, {\"qty\": 2}]}")
    for (e in schema.validate(body)) { print(e.toString()) }
    print(schema.isValid(Json.parse("{\"id\": 7, \"email\": \"ada@acme.test\", \"lines\": []}")))

    let s = JsonSchema.parse("{\"type\": \"array\", \"items\": {\"enum\": [\"red\", \"green\"]}, \"uniqueItems\": true}")
    for (e in s.validate(Json.parse("[\"red\", \"blue\", \"red\"]"))) { print("${e.path} ${e.keyword}: ${e.message}") }
}
```

Output:

```text
/email: must be a valid email
/lines/0/qty: must be at least 1
/lines/1/sku: is required
true
/1 enum: must be one of ["red","green"]
/2 uniqueItems: repeats item 0
```

- **Checked keywords.** `type`, `enum`, `const`; `minimum`, `maximum`,
  `exclusiveMinimum`, `exclusiveMaximum`, `multipleOf`; `minLength`, `maxLength`,
  `pattern`, `format` (email, uri, date, date-time, time, uuid, ipv4, ipv6,
  hostname); `properties`, `required`, `additionalProperties`,
  `patternProperties`, `propertyNames`, `minProperties`, `maxProperties`,
  `dependentRequired`; `items`, `prefixItems`, `minItems`, `maxItems`,
  `uniqueItems`, `contains`; `allOf`, `anyOf`, `oneOf`, `not`, `if`/`then`/`else`;
  `$ref` to anywhere in the same document (`#/$defs/…`), recursion included; and
  `nullable`. Annotations (`title`, `description`, `examples`, …) are left alone,
  as are unknown formats. Patterns are ECMAScript-style: `\d`, `\w`, `\s` work.
- **Errors** (`JsonSchemaError`) give a JSON Pointer `path` to the value, a
  `message`, and the `keyword`; at most `maxErrors` (100) are collected.
- **From a class.** `JsonSchema.forClass(reflect(T))` describes the fields
  JsonMap maps: their keys (`@JsonName`, `@JsonSnakeCase`), types, and nested
  classes under `$defs`. Fields whose type is not `T?` are required.
  `@Schema(...)` on a field adds keywords to its property (`min` and `max` are
  `minimum` and `maximum`; `format`, `pattern`, `minLength`, `description`,
  `example`, … as named).
- **Speed.** `compile` reads each keyword once into a tree of nodes (patterns
  compiled, `$ref`s resolved once), so checking an order of five fields and
  three lines takes about 8 µs.
