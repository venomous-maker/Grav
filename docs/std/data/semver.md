# Semver

`import "std/data"` (included in `import "std"`) · namespace `std.data`

Semantic versions (semver.org 2.0): parsing, ordering (a prerelease comes
before its release, numeric identifiers compare as numbers) and ranges in npm's
syntax: `=`, `>`, `>=`, `<`, `<=`, `^` (the same leftmost non-zero part), `~`
(the same minor), `x` wildcards, hyphen ranges (`1.2 - 1.4`), a space for
"and" and `||` for "or". As in npm, a prerelease version satisfies a range only
when a comparator names a prerelease of the same version, so `^1.0` never picks
`2.0.0-beta`.

```grav
import "std"

fn main() {
    print(Semver.satisfies("1.4.2", "^1.2"))
    print(Semver.satisfies("2.0.0-beta.1", "^1.0"))
    print(Semver.maxSatisfying(["1.2.0", "1.9.9", "2.1.0"], "~1.9"))
    print(Semver.sort(["1.0.0", "1.0.0-rc.1", "1.0.0-beta.11", "1.0.0-beta.2"]))
    print(Semver.parse("1.2.3").nextMinor().toString())
}
```

Output:

```text
true
false
1.9.9
["1.0.0-beta.2", "1.0.0-beta.11", "1.0.0-rc.1", "1.0.0"]
1.3.0
```
