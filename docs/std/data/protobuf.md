# protobuf

`import "std/data"` (included in `import "std"`) · namespace `std.data`

Protocol Buffers: messages encoded and decoded from a `.proto` schema as JSON values,
with no code generation, and the wire format read and written field by field.

```grav
import "std"

fn main() {
    let schema = ProtoSchema.parse("""
        syntax = "proto3";
        package shop;
        message Order {
          string id = 1;
          enum Status { PENDING = 0; PAID = 1; SHIPPED = 2; }
          Status status = 2;
          message Line { string sku = 1; int32 qty = 2; double price = 3; }
          repeated Line lines = 3;
          map<string, string> tags = 4;
        }
        """)
    let order = Json.parse("{\"id\": \"INV-42\", \"status\": \"PAID\", \"lines\": [{\"sku\": \"TEA\", \"qty\": 2, \"price\": 2.5}], \"tags\": {\"channel\": \"web\"}}")
    let bytes = schema.encode("Order", order)
    print("${bytes.size()} bytes (JSON: ${order.toJson().length})")
    print(bytes.toHex())
    print(schema.decode("shop.Order", bytes).toJson())

    let w = new ProtoWriter().string(1, "Ada").int32(2, 150).packedVarints(3, [1, 2, 3])
    let r = new ProtoReader(w.toBytes())
    while (r.next()) {
        if (r.field == 1) { print(r.string()) }
        else if (r.field == 2) { print(r.varint()) }
        else { print(r.packedVarints()) }
    }
}
```

- **Schemas**: `ProtoSchema.parse(source)` reads proto2 and proto3 files: packages,
  nested messages and enums, `repeated` and packed fields, `oneof`, `map<K, V>`,
  `optional`, and all scalar types. `import`, `option`, `reserved`, `extend` and
  `service` blocks are read and ignored. `add(source)` adds another file's types to the
  same schema. Type names resolve from the inner scope outward, as protoc does.
  Messages are found by full name (`shop.Order`) or by the end of it (`Order`).
- **JSON mapping**: field names stay as declared, and camelCase is accepted on input.
  Enums are their names. `bytes` are Base64. 64-bit integers are numbers. Maps are
  objects. A proto3 field holding its default is left out on encoding, and absent
  fields are not filled in on decoding. Unknown fields in the input bytes are skipped;
  unknown JSON keys are a `ValueError`.
- **Output** is byte-for-byte what Google's protobuf libraries produce. Fields are
  written in number order and repeated scalars packed in proto3. Tests compare it with
  the python-protobuf runtime.
- **The wire format**: `ProtoWriter` has a method per scalar type (`int32`, `sint64`,
  `fixed32`, `float64`, `string`, `bytes`, …), plus `message` for nesting and
  `packedVarints` and `packedDoubles`. `ProtoReader.next()` moves from field to field
  (`field`, `wireType`); the matching reader takes the value, or `skip()` passes it.
  `message()` reads a nested message in place, without copying it.
- gRPC framing will build on this.
