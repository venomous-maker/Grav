# Zip

`import "std/data"` (included in `import "std"`) · namespace `std.data`

ZIP archives, written (each entry stored or deflated, whichever is smaller)
and read, compatible with `zip`/`unzip`, Python's `zipfile` and the rest (and
so with `.docx`, `.xlsx` and `.jar` files, which are ZIPs). Reading checks each
entry's CRC, inflates with a size limit (`maxEntryBytes`, 1 GiB by default) so
a small archive cannot expand into gigabytes, and `extractTo` refuses names
that would land outside its folder ("zip slip"). ZIP64 (over 4 GiB) is not
supported.

```grav
import "std"

fn main() {
    let z = new ZipWriter()
    z.addText("readme.txt", "hello")
    z.add("data/rows.csv", Bytes.fromString(Str.repeat("1,2,3\n", 1000)))
    let bytes = z.toBytes()

    let r = ZipReader.open(bytes)
    for (e in r.entries()) { print("${e.name}: ${e.size} bytes, method ${e.method}") }
    print(r.readText("readme.txt"))
    print(bytes.size() < 300)                 // 6 KB of rows in under 300 bytes
}
```

Output:

```text
readme.txt: 5 bytes, method 0
data/rows.csv: 6000 bytes, method 8
hello
true
```
