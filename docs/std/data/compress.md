# Compress

`import "std/data"` (included in `import "std"`) · namespace `std.data`

gzip, zlib and raw deflate compression, using the system's zlib (loaded the
first time it is needed). The formats are the ones `.gz` files, HTTP
`Content-Encoding` and zip archives use, so the results interoperate with
`gzip`, browsers and other languages.

```grav
import "std"

fn main() {
    let text = Str.repeat("the same words again and again ", 300)
    let packed = Compress.gzipText(text)
    print("${text.length} bytes -> under 1%: ${packed.size() * 100 < text.length}, gzip: ${Compress.isGzip(packed)}")
    print(Compress.gunzipText(packed) == text)

    let z = Compress.deflate(Bytes.fromString(text), 9)
    print(Compress.inflate(z).size())

    try {
        Compress.decompress(Compress.gzipText(Str.repeat("a", 100000)), 1000)
    } catch (e: ValueError) {
        print(e.message())
    }
}
```

Output:

```text
9300 bytes -> under 1%: true, gzip: true
true
9300
the data decompresses to more than the limit
```

- **gzip:** `gzip(data[, level])`, `gunzip(data)`, `gzipText`, `gunzipText`.
  Levels go from 1 (fastest) to 9 (smallest), 0 stores without compressing; the
  default is 6.
- **zlib** (HTTP's `deflate`): `deflate(data[, level])` and `inflate(data)`.
  **Raw deflate** (no header, as in zip files): `deflateRaw` and `inflateRaw`.
- **Any of them:** `decompress(data, maxBytes)` detects the format and stops
  with `ValueError` past `maxBytes`, so a small hostile input cannot expand into
  gigabytes (`gunzip` and `inflate` allow up to 1 GiB).
- `isGzip(data)` and `isZlib(data)` look at the first bytes.
- Corrupt or truncated input throws `ValueError` saying which. Without zlib,
  `Compress.available()` is false and the calls throw `StateError`.
- [`HttpServer.compress(true)`](../net/http_server.md) and
  [`HttpClient`](../net/http_client.md) use this for HTTP compression.

- `static fn inflate(data: Bytes) -> Bytes` — The bytes of zlib (or gzip) data.
- `static fn inflateRaw(data: Bytes) -> Bytes` — The bytes of raw deflate data.
- `static fn decompress(data: Bytes, maxBytes: int) -> Bytes` — Decompresses gzip, zlib or raw deflate data (whichever it is), producing at most `maxBytes` bytes (ValueError beyond that).
- `static fn gzipText(text: string) -> Bytes` — Text gzip-compressed.
- `static fn gunzipText(data: Bytes) -> string` — gzip data decompressed to text.

- `static fn isZlib(data: Bytes) -> bool` — Whether the data starts like a zlib stream.
