# MimeType

`import "std/data"` (included in `import "std"`) · namespace `std.data`

Media (MIME) types by file extension and back, for serving files, naming
uploads and setting `Content-Type`. Unknown extensions are
`application/octet-stream`. `isText` and `isCompressible` say whether a type is
readable text and whether it is worth compressing in transfer.

```grav
import "std"

fn main() {
    print(MimeType.of("report.PDF"))
    print(MimeType.of("assets/app.woff2"))
    print(MimeType.extensionOf("image/jpeg"))
    print("${MimeType.isText("application/ld+json")} ${MimeType.isCompressible("image/png")}")
}
```

Output:

```text
application/pdf
font/woff2
jpg
true false
```
