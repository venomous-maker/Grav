# Crypto

`import "std/data"` (included in `import "std"`) · namespace `std.data`

Cryptography through the system's OpenSSL (`libcrypto`, loaded the first time it
is needed): digests and HMAC with SHA-1, SHA-256, SHA-384 and SHA-512; secure
random bytes and constant-time comparison; AES-GCM authenticated encryption;
asymmetric keys (RSA, ECDSA on P-256/P-384/P-521, Ed25519) that sign and verify
and read and write PEM and JWK; and scrypt password hashes. Key generation and
JWK output need OpenSSL 3 (`Crypto.hasKeyGeneration()`).

```grav
import "std"

fn main() {
    print(Crypto.sha512(Bytes.fromString("abc")).toHex()[..16])
    print(Crypto.hmac("sha256", Bytes.fromString("Jefe"), Bytes.fromString("what do ya want for nothing?")).toHex()[..16])

    let key = AesGcm.generateKey()
    let sealed = AesGcm.encrypt(key, Bytes.fromString("attack at dawn"))
    print(AesGcm.decrypt(key, sealed).toString())

    let signer = CryptoKey.generate("ed25519")
    let msg = Bytes.fromString("hello")
    let sig = signer.sign(msg)
    let pub = CryptoKey.fromPem(signer.publicPem())
    print("${pub.kind()}: ${pub.verify(msg, sig)}, tampered: ${pub.verify(Bytes.fromString("hellp"), sig)}")

    PasswordHash.costLog = 12            // (the default, 15, takes 32 MiB and ~0.1 s)
    let h = PasswordHash.make("hunter2")
    print("${Str.startsWith(h, "$scrypt$")} ${PasswordHash.verify("hunter2", h)} ${PasswordHash.verify("hunter3", h)}")
}
```

Output:

```text
ddaf35a193617aba
5bdcc146bf60754e
attack at dawn
ed25519: true, tampered: false
true true false
```

- **AES-GCM** output is the nonce (12 bytes, random each time), the ciphertext
  and the tag (16 bytes). Decrypting checks the tag: altered data, other
  associated data or the wrong key is a `ValueError`, never garbage.
- **Keys**: `CryptoKey.generate("rsa" | "rsa-2048" | "rsa-4096" | "p256" | "p384" |
  "p521" | "ed25519")`, `fromPem` (private or public, any common PEM form),
  `fromJwk` (public). ECDSA signatures from `sign` are DER; [JWT](jwt.md) turns
  them into the `r || s` form JWS uses.
- **Passwords**: `PasswordHash.make` writes `$scrypt$ln=15,r=8,p=1$<salt>$<hash>`,
  carrying its own settings, so `verify` keeps working after the defaults change
  and `needsRehash` says when to store a stronger one.
- `Crypto.equals` compares bytes in time that depends only on their lengths;
  `Hash.equals` does the same for strings.

### class CryptoKey

An asymmetric key: RSA, ECDSA (P-256, P-384, P-521) or Ed25519, private
(signs, and holds its public half) or public (verifies).

### class PasswordHash

Password hashes with scrypt (memory-hard), as text that carries its own
parameters and salt: "$scrypt$ln=15,r=8,p=1$<salt>$<hash>". The default
cost (N = 2^15, r = 8) uses 32 MiB and about a tenth of a second per hash.

**Static members**

- `static costLog: int = 15` — log2 of N, r and p for new hashes.
- `static blockSize: int = 8`
- `static parallelism: int = 1`
- `static fn make(password: string) -> string`
- `static fn verify(password: string, hash: string) -> bool` — Whether `password` is the one `hash` was made from (false for text that is not such a hash).
- `static fn needsRehash(hash: string) -> bool` — Whether `hash` was made with weaker settings than the current ones (make a new one at sign-in).
