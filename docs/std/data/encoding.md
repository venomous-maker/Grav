# Base64, Hex and Utf8

`import "std/data"` (included in `import "std"`) · namespace `std.data`

Encodings that turn bytes into text and back, and helpers for working with UTF-8
text by character.

- **`Base64`** represents binary data with 64 safe characters: for embedding data
  in JSON, URLs, e-mail or HTTP headers. `encodeUrl` uses the URL- and
  filename-safe alphabet without padding.
- **`Hex`** writes each byte as two hexadecimal digits.
- **`Utf8`** counts, splits and slices text by character (code point) rather than by
  byte, which matters for anything beyond plain ASCII.

```grav
import "std"

fn main() {
    let token = Base64.encode("user:secret")
    print(token)
    print(Base64.decode(token))
    print(Base64.encodeUrl("??>>"))
    print(Hex.encode("Hi!"))
    print(Hex.decode("47726176"))
    print(Utf8.count("naïve"))
    print("naïve".length)
    print(Utf8.chars("añb"))
    print(Utf8.codePoints("€"))
    print(Utf8.fromCodePoint(128512))
    print(Utf8.reverse("añb"))
}
```

- Decoding text that is not valid Base64 or hex throws `ValueError`;
  `Base64.isValid` checks without throwing. Base64 decoding accepts both
  alphabets, with or without padding, and ignores whitespace.
- `decode` returns a `string`; for data that may contain zero bytes use
  `decodeBytes`, which returns [`Bytes`](bytes.md).
- `Utf8.codePoints` gives -1 for a byte sequence that is not valid UTF-8, and
  `Utf8.isValid` checks a whole string.

### class Base64

Base64: binary data as text (RFC 4648), standard or URL-safe.

**Static members**

- `static fn encode(s: string) -> string` — The Base64 text of a string's bytes, with = padding.
- `static fn encodeBytes(b: Bytes) -> string` — The Base64 text of raw bytes, with = padding.
- `static fn encodeUrl(s: string) -> string` — URL- and filename-safe Base64 (- and _ instead of + and /, no padding).
- `static fn decode(s: string) -> string` — The text that Base64 `s` encodes (standard or URL-safe; padding and whitespace optional); ValueError when `s` is not Base64. Use decodeBytes for binary data.
- `static fn decodeBytes(s: string) -> Bytes` — The bytes that Base64 `s` encodes; ValueError when `s` is not Base64.
- `static fn isValid(s: string) -> bool` — Whether `s` is valid Base64.

### class Hex

Hexadecimal: each byte as two hex digits.

**Static members**

- `static fn encode(s: string) -> string` — The hex digits of a string's bytes, lowercase: Hex.encode("Hi") == "4869".
- `static fn encodeUpper(s: string) -> string` — The same in uppercase.
- `static fn encodeBytes(b: Bytes) -> string` — The hex digits of raw bytes, lowercase.
- `static fn decode(s: string) -> string` — The text the hex digits encode; ValueError for an odd length or a non-hex digit.
- `static fn decodeBytes(s: string) -> Bytes` — The bytes the hex digits encode; ValueError for an odd length or a non-hex digit.

### class Utf8

UTF-8 text by character (code point) rather than by byte.

**Static members**

- `static fn count(s: string) -> int` — The number of characters (code points); "héllo" has 5 (and 6 bytes).
- `static fn chars(s: string) -> Array<string>` — The characters, each as a one-character string.
- `static fn codePoints(s: string) -> Array<int>` — The Unicode code point of each character (-1 for an invalid byte sequence).
- `static fn fromCodePoint(cp: int) -> string` — The one-character string for a code point (U+FFFD for an invalid one).
- `static fn fromCodePoints(cps: Array<int>) -> string` — The string made of these code points.
- `static fn isValid(s: string) -> bool` — Whether `s` is well-formed UTF-8.
- `static fn slice(s: string, start: int, end: int) -> string` — The characters from index `start` up to (not including) `end`, counted in characters.
- `static fn reverse(s: string) -> string` — The characters in reverse order (unlike Str.reverse, which reverses bytes).
