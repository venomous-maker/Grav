# Bytes

`import "std/data"` (included in `import "std"`) · namespace `std.data`

`Bytes` is a growable buffer of raw bytes. Unlike a `string`, it can contain zero
bytes, so it suits binary file formats and network protocols. Elements are read
and written as `int`s from 0 to 255, with bounds-checked indexing.

```grav
import "std"

fn main() {
    let b = new Bytes()
    b.appendByte(0x47).appendString("RV")
    b.appendUint(258, 2)                 // a 2-byte big-endian number
    print(b.size())
    print(b.toHex())
    print(b[0])
    print(b.readUint(3, 2))
    print(b.slice(0, 3).toString())

    let c = Bytes.fromHex("00ff10")
    print(c[1])
    c[1] = 7
    print(c.toHex())
    print(Bytes.fromString("hi") == Bytes.fromHex("6869"))
}
```

Output:

```text
5
4752560102
71
258
GRV
255
000710
true
```

`appendUint(v, width)` and `readUint(at, width)` write and read big-endian
(network order) unsigned numbers of 1 to 8 bytes. `toBinary()` and
`Bytes.fromBinary(x)` convert to and from the built-in `binary` type, which is what
`File.readBinary` returns. Sockets read and write `Bytes` directly
([TCP](../net/tcp.md)).
