# JSON

`import "std/data"` (included in `import "std"`) · namespace `std.data`

Reading, building and writing JSON. `Json.parse` turns text into a `JsonValue`,
a tree you can walk; `Json.object()` and `Json.array()` start new values you build
with `set` and `push`; `toJson()` and `pretty()` turn a value back into text.

```grav
import "std"

fn main() {
    let doc = Json.parse("{\"name\": \"grav\", \"tags\": [\"fast\", \"small\"], \"stars\": 42}")
    print(doc["name"].asString())
    print(doc["tags"][1].asString())
    print(doc.getInt("stars", 0))
    print(doc["owner"]["login"].isNull())
    print(doc.path("tags.0").asString())
    for (t in doc["tags"].asArray()) { print("tag: ${t.asString()}") }

    let out = Json.object()
        .set("ok", true)
        .set("count", 3 as long)
        .set("items", Json.array().push("a").push(1.5))
    print(out.toJson())
    print(out.pretty())

    try {
        Json.parse("{\"a\": }")
    } catch (e: ValueError) {
        print(e.message())
    }
    print(Json.tryParse("not json") == null)
}
```

Output:

```text

small
42
true
fast
tag: fast
tag: small
{"ok":true,"count":3,"items":["a",1.5]}

  "items": [

  ]
}

true
```

- **Lookups never fail.** A missing key or index gives a JSON `null`, so chains
  like `doc["a"]["b"][0]` are safe. Check with `isNull()` or `has(key)`.
- **`asString()`, `asInt()` and the other `asX()`** throw `TypeError` when the
  value is of another kind. `getString(key, fallback)` and the other `getX`
  methods return the fallback instead.
- **`path("a.b.0")`** follows a dotted path of keys and indexes.
- **Numbers**: integers are kept exactly as 64-bit values (`asLong()`); other
  numbers are doubles.
- **Objects keep insertion order.** `set` replaces an existing key in place;
  `remove(key)` deletes one.
- **`==`** compares structure; the order of object keys does not matter.
- `Json.parse` throws `ValueError` with a line and column; `Json.tryParse` returns
  `null` instead. `Json.quote(s)` escapes a string as a JSON literal.
