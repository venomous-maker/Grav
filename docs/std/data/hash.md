# Hash and Uuid

`import "std/data"` (included in `import "std"`) · namespace `std.data`

Hash functions turn data of any size into a short fingerprint: the same input
always gives the same output, and different inputs almost never collide. `Uuid`
makes random identifiers that are, in practice, unique everywhere.

| Function | Gives | Use it for |
|----------|-------|------------|
| `Hash.sha256(s)` | 64 hex digits | integrity checks, fingerprints, content addressing |
| `Hash.sha1(s)`, `Hash.md5(s)` | 40 / 32 hex digits | compatibility with formats that use them (both are broken for security) |
| `Hash.crc32(s)` | a number below 2³² | quick checksums, as in zip, gzip and PNG |
| `Hash.fnv1a(s)` | a 64-bit number | fast hashing for tables and caches |
| `Hash.randomToken(n)` | 2n hex digits | session ids, password-reset tokens, nonces |
| `Uuid.v4()` | `xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx` | database keys, request ids |

```grav
import "std"

fn main() {
    print(Hash.sha256("abc"))
    print(Hash.md5("abc"))
    print(Hash.crc32("hello"))
    let fileData = Bytes.fromString("pretend these are file contents")
    print(Hash.sha256Bytes(fileData).length)

    let id = Uuid.v4()
    print(Uuid.isValid(id))
    print(id.length)
    print(Hash.randomToken(16).length)
}
```

Hashes are not encryption: they cannot be reversed. Plain SHA-256 is not suitable
for storing passwords either, because it is too fast to compute; use a dedicated
password-hashing algorithm for that. `Uuid.v4` and `Hash.randomToken` use the
operating system's random source, unlike [`Random`](../core/random.md), which is
predictable by design.

### class Hash

Hashes and checksums of text or bytes. The hash functions return lowercase hex.

**Static members**

- `static fn sha256(s: string) -> string` — SHA-256 of the string's bytes, as 64 hex digits.
- `static fn sha256Bytes(b: Bytes) -> string` — SHA-256 of raw bytes, as 64 hex digits.
- `static fn sha1(s: string) -> string` — SHA-1 of the string's bytes, as 40 hex digits (legacy: not for security).
- `static fn md5(s: string) -> string` — MD5 of the string's bytes, as 32 hex digits (legacy: not for security).
- `static fn md5Bytes(b: Bytes) -> string` — MD5 of raw bytes, as 32 hex digits (legacy: not for security).
- `static fn crc32(s: string) -> long` — CRC-32 checksum (the one zip, gzip and PNG use), from 0 to 4294967295.
- `static fn crc32Bytes(b: Bytes) -> long` — CRC-32 checksum of raw bytes.
- `static fn fnv1a(s: string) -> long` — FNV-1a, a fast 64-bit hash for hash tables and fingerprints (not for security).
- `static fn randomToken(n: int) -> string` — `n` random bytes from the operating system, as 2n hex digits: for session ids, tokens and nonces (n is at most 256).

### class Uuid

Universally unique identifiers (RFC 4122).

**Static members**

- `static fn v4() -> string` — A random (version 4) UUID such as "3f2b9c1e-8d4a-4f6b-9a2e-7c1d5e8f0a3b", from the operating system's random source.
- `static fn nil() -> string` — The all-zero UUID.
- `static fn isValid(s: string) -> bool` — Whether `s` has the form xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx (hex digits, any case).
