# pdf

`import "std/data"` (included in `import "std"`) · namespace `std.data`

PDF documents written from code: invoices, receipts, reports and tickets. Text can use
the standard fonts or an embedded TrueType font (for any language). There are wrapped
and justified paragraphs, lines, rectangles and circles, images (pixels or JPEG files
as they are), QR codes as vectors, links, and tables that continue onto new pages with
their header repeated.

```grav
import "std"

fn main() {
    let doc = new PdfDocument()
    doc.title = "Invoice INV-0042"
    let page = doc.addPage()
    page.setFont(doc.font("Helvetica-Bold"), 20).text(50, 50, "Invoice INV-0042")
    page.setFont(doc.font("Helvetica"), 10).setFillColor(0x555555)
        .text(50, 78, "Issued 15 Jan 2025 · Due 30 Jan 2025")
    page.setFillColor(0x000000)
    let used = page.textBox(50, 100, 300, "Thank you for your business. Payment is due within fifteen days of the invoice date.")
    let t = new PdfTable([250, 60, 120]).header(["Item", "Qty", "Amount"]).alignRight(1).alignRight(2)
    t.row(["Hosting, January", "1", "KES 1,200.00"]).row(["Support hours", "3", "KES 4,500.00"])
    let last = doc.table(t, page, 50, 100 + used + 20)
    last.setFont(doc.font("Helvetica-Bold"), 11).textRight(480, last.lastTableBottom + 10, "Total: KES 5,700.00")
    last.qrCode(QrCode.encode("https://pay.example.test/inv/42"), 50, last.lastTableBottom + 40, 90)
    last.link(50, last.lastTableBottom + 40, 90, 90, "https://pay.example.test/inv/42")
    let bytes = doc.bytes()
    print("${doc.pageCount()} page, starts ${bytes.slice(0, 8).toString()}")
    let w = doc.font("Helvetica").width("Invoice", 10)
    print("'Invoice' is ${w} pt wide in 10 pt Helvetica")
}
```

Output:

```text
1 page, starts %PDF-1.7
'Invoice' is 31.68 pt wide in 10 pt Helvetica
```

- **Coordinates** are points (1/72 inch) from the page's top-left corner, with y
  downward. Text is placed by the top of its line. The default page is A4
  (`new PdfDocument(612, 792)` for US Letter; `PdfDocument.a4()`, `a5()`, `a3()`,
  `letter()`, `legal()` give the sizes). `addPage(w, h)` can mix page sizes.
- **Fonts**: `doc.font(name)` gives one of the standard fonts: Helvetica, Times-Roman,
  Courier, each with Bold and Oblique/Italic. They need nothing embedded and cover
  Western European text (Windows-1252). `doc.loadFont("DejaVuSans.ttf")` embeds a
  TrueType font for any other script, with a ToUnicode map so text can still be
  copied and searched. `textWidth`, `font.width(text, size)` and `wrap` measure with
  the font's real widths.
- **Text**: `text`, `textRight`, `textCenter`, and `textBox(x, y, width, text, align,
  lineHeight)`, which wraps at spaces, splits words longer than a line, keeps `"\n"`,
  and aligns left, right, center or justify. It returns the height it used.
- **Shapes and colour**: `line`, `rect`, `fillRect`, `roundRect`, `circle`,
  `setFillColor` and `setStrokeColor` (`0xRRGGBB`), `setLineWidth`, `setDash`. `raw`
  takes PDF operators directly.
- **Images**: `doc.addImage(img)` stores an [`Image`](image.md) once, compressed, with
  transparency as a soft mask. `doc.addJpeg(bytes)` embeds a JPEG as it is. `page.image`
  draws either into a box, keeping the aspect ratio when the height is 0.
  `drawImage(img, …)` does both steps at once.
- **Tables**: `PdfTable` takes column widths, a header, rows, per-column alignment,
  stripes, colours and fonts. `doc.table(t, page, x, y)` adds pages as needed, repeats
  the header on each, and returns the page it ended on. That page's `lastTableBottom`
  says where the table stopped.
- **Also**: `link` (a clickable area), `qrCode` (vector modules, sharp at any zoom),
  and metadata (`title`, `author`, `subject`, `keywords`, `creator`). `bytes()` gives
  the file and `save(path)` writes it. Page contents, images and fonts are
  Flate-compressed when zlib is present (`compress = false` turns that off for
  inspection).
