# Sort

`import "std/core"` (included in `import "std"`) · namespace `std.core`

Sorting and binary search for `Array`s. `Sort.sort` sorts arrays of numbers and
strings in their natural order; `Sort.sortBy` sorts anything with a comparison
function. All sorts are stable (equal elements keep their order) and use TimSort,
which is especially fast on data that is already partly sorted.

A comparison function `cmp(a, b)` returns a negative number when `a` comes first,
a positive number when `b` comes first, and 0 when they are equal.

```grav
import "std"

class Player {
    public name: string
    public score: int
    constructor(name: string, score: int) { self.name = name; self.score = score }
}

fn main() {
    let nums: Array<int> = [5, 3, 9, 1]
    Sort.sort(nums)
    print(nums)
    print(Sort.binarySearch(nums, 9))
    print(Sort.binarySearch(nums, 4))      // not found: -(insertion point) - 1

    let names: Array<string> = ["pear", "fig", "apple"]
    Sort.sortDescending(names)
    print(names)

    let players = new Array<Player>()
    players.push(new Player("ann", 30))
    players.push(new Player("bob", 50))
    players.push(new Player("cy", 30))
    Sort.sortBy(players, fn(a, b) => b.score - a.score)   // highest first
    for (p in players) { print("${p.name} ${p.score}") }
}
```

Output:

```text
[1, 3, 5, 9]
3
-3
["pear", "fig", "apple"]
bob 50
ann 30
cy 30
```

`Array.sortBy(cmp)` does the same as `Sort.sortBy(array, cmp)`. A comparison that
is not consistent (it says `a < b` and `b < a`) can make the sort throw a
`ValueError`.
