# Math

`import "std/core"` (included in `import "std"`) · namespace `std.core`

Mathematical functions and constants, from C's `<math.h>`. Floating-point
functions take and return `float` (64-bit). `abs`, `min`, `max`, `clamp` and
`sign` also have `int` and `long` versions, so `Math.max(3, 7)` stays an `int`.
Angles are in radians.

```grav
import "std"

fn main() {
    print(Math.sqrt(16.0))
    print(Math.pow(2.0, 10.0))
    print(Math.max(3, 7))
    print(Math.clamp(150, 0, 100))
    print(Math.roundTo(Math.PI, 3))
    print(Math.round(2.5))
    print(Math.floor(-1.5))
    print(Math.hypot(3.0, 4.0))
    print(Math.gcd(84, 36))
    print(Math.isPrime(97))
    print(Math.factorial(10))
    print(Math.toDegrees(Math.atan2(1.0, 1.0)))
}
```

Output:

```text

1024
7
100
3.142
3
-2
5
12
true

```

- `round` rounds halves away from zero; `trunc` cuts toward zero; `floor` and
  `ceil` go down and up.
- `isNaN`, `isInfinite` and `isFinite` check float results: `0.0 / 0.0` is NaN,
  `1.0 / 0.0` is infinite.
- `factorial` overflows past 20!.

For random numbers see [`Random`](random.md).
