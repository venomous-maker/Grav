# Math

`import "std/core"` (included in `import "std"`) · namespace `std.core`

Mathematical functions and constants, from C's `<math.h>`. Floating-point
functions take and return `float` (64-bit). `abs`, `min`, `max`, `clamp` and
`sign` also have `int` and `long` versions, so `Math.max(3, 7)` stays an `int`.
Angles are in radians.

```grav
import "std"

fn main() {
    print(Math.sqrt(16.0))
    print(Math.pow(2.0, 10.0))
    print(Math.max(3, 7))
    print(Math.clamp(150, 0, 100))
    print(Math.roundTo(Math.PI, 3))
    print(Math.round(2.5))
    print(Math.floor(-1.5))
    print(Math.hypot(3.0, 4.0))
    print(Math.gcd(84, 36))
    print(Math.isPrime(97))
    print(Math.factorial(10))
    print(Math.toDegrees(Math.atan2(1.0, 1.0)))
}
```

- `round` rounds halves away from zero; `trunc` cuts toward zero; `floor` and
  `ceil` go down and up.
- `isNaN`, `isInfinite` and `isFinite` check float results: `0.0 / 0.0` is NaN,
  `1.0 / 0.0` is infinite.
- `factorial` overflows past 20!.

For random numbers see [`Random`](random.md).

## More functions

`logBase`, `root`, integer `ipow` and `isqrt`, `floorDiv`/`floorMod` (which round
toward negative infinity, so `floorMod(-7, 3)` is 2), `lerp` and `mapRange` for
interpolation, `isClose` for comparing computed floats, `binomial`, `fib`,
`primeFactors`, `isPowerOfTwo`/`nextPowerOfTwo`, and the constants `SQRT2`,
`LN2`, `LN10` and `PHI`.

```grav
import "std"

fn main() {
    print(Math.logBase(1024.0, 2.0))
    print(Math.floorMod(-7, 3))
    print(Math.mapRange(25.0, 0.0, 100.0, 0.0, 255.0))
    print(Math.isClose(0.1 + 0.2, 0.3, 1e-9))
    print(Math.binomial(52, 5))
    print(Math.primeFactors(360))
}
```

Output:

```text
10
2
63.75
true
2598960
[2, 2, 2, 3, 3, 5]
```

## Stats

`Stats` summarises a list of numbers (`Array<float>` or `Array<int>`): `sum`,
`mean`, `median`, `min`, `max`, `variance`, `sampleVariance`, `stddev`,
`percentile`, `mode` and `correlation`. An empty list throws `ValueError`.

```grav
import "std"

fn main() {
    let times: Array<float> = [12.0, 15.0, 11.0, 30.0, 14.0, 13.0]
    print(Stats.mean(times))
    print(Stats.median(times))
    print(Math.roundTo(Stats.stddev(times), 2))
    print(Stats.percentile(times, 90.0))
    let rolls: Array<int> = [3, 6, 3, 1, 3, 6]
    print(Stats.mode(rolls))
}
```

Output:

```text
15.833333333333334
13.5
6.47
22.5
3
```
