# bigint

`import "std/types"` (included in `import "std"`) · namespace `std.types`

Whole numbers of any size: cryptography, exact factorials and combinatorics, amounts in
the smallest unit past 2^63, and IDs from other systems. A `BigInt` is immutable, and
the operators work on it as on a `long`, with whole numbers mixing in on the right.

```grav
import "std"

fn main() {
    let a = BigInt.parse("123456789012345678901234567890")
    print(a * a + BigInt.one())
    print(BigInt.of(2).pow(128))
    print(BigInt.factorial(25))
    print(BigInt.binomial(60, 30))
    print("${a / 1000} ${a % 97} ${a > BigInt.of(1)}")
    print("${BigInt.of(-7) / BigInt.of(2)} ${BigInt.of(-7) % BigInt.of(2)} ${BigInt.of(-7).mod(BigInt.of(2))}")
    print("${BigInt.parse("ff_ff", 16)} ${BigInt.of(255).toString(2)}")
    print(BigInt.of(7).modPow(BigInt.of(560), BigInt.of(561)))
    print(BigInt.parse("170141183460469231731687303715884105727").isProbablePrime())
    print(BigInt.of(10).pow(40).sqrt())
}
```

- **Arithmetic**: `+ - * / %` (and `plus`, `minus`, `times`, `div`, `rem`, `divRem` for
  both at once), `negate`, `abs`, `pow(e)`, `sqrt` (the integer root), `gcd`. `/` and
  `%` truncate toward zero and the remainder takes the dividend's sign, as for `long`;
  `mod(m)` is never negative. Division by zero is an `ArithmeticError`.
- **Modular arithmetic**: `modPow(e, m)` (a negative `e` uses the inverse),
  `modInverse(m)`, and `isProbablePrime(rounds)` (Miller–Rabin; exact below about
  3.3 × 10^24 with the default 12 rounds).
- **Bits**: `shiftLeft`, `shiftRight` (rounding toward negative infinity, as `>>`),
  `bitLength`, `testBit`, and `and`, `or`, `xor` for non-negative values.
- **Conversions**: `BigInt.of(long)`, `parse(text, base)` (bases 2 to 36, an optional
  sign, `_` between digits), `tryParse`, `toString(base)`, `toHex`, `toLong` and
  `toInt` (an `ArithmeticError` when the value does not fit; `fitsLong()` asks first),
  and `toDouble`.
- **Speed**: the digits are 32-bit limbs handled in C. Multiplication is schoolbook
  below 40 limbs and Karatsuba above, division is Knuth's algorithm D, `factorial` and
  `binomial` multiply in a balanced product tree, and `modPow` reduces after every
  step instead of building the huge power.
