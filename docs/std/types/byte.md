# Byte

`import "std/types"` (included in `import "std"`) · namespace `std.types`

Indexing a string gives a byte (`s[i]`). `Byte` holds the ASCII tests and case
changes for them, as methods of any byte (which also has
[Integer](integer.md)'s).

```grav
import "std"

fn main() {
    let s = "a1 B"
    print("${s[0].isLetter()} ${s[1].isDigit()} ${s[2].isSpace()} ${s[3].isUpper()}")
    print(s[0].toUpper().toChar() + " " + s[3].toLower().toChar() + " " + s[0].toHex())
    print("f"[0].digitValue())
}
```

Output:

```text
true true true true
A b 61
15
```

The tests are ASCII only: the bytes of other UTF-8 characters are none of them.
