# Float

`import "std/types"` (included in `import "std"`) · namespace `std.types`

`Float` holds what floating-point numbers can do beyond arithmetic, as methods
of any float (`x.round(2)` is `Float.round(x, 2)`), with the special values
named: `NaN` and `Infinity` (also `Float.NAN`, `Float.INFINITY`,
`Float.NEGATIVE_INFINITY`), which print as `NaN`, `Infinity` and `-Infinity`.

```grav
import "std"

fn main() {
    let x = 3.14159
    print("${x.round(2)} ${x.toFixed(4)} ${2.75.floor()} ${0.256.toPercent(1)}")
    print("${Float.parse("2.5e3")} ${0.1.toDecimal()} ${7.0.isWhole()}")
    let r = 0.0 / 0.0
    print("${r} ${r.isNaN()} ${r == NaN} ${1.0 / 0.0 == Infinity} ${-Infinity}")
}
```

Output:

```text
3.14 3.1416 2 25.6%
2500 0.1 true
NaN true false true -Infinity
```

- NaN is not `==` to anything, itself included: test it with `x.isNaN()`.
  `Float.compare` (for sorting) puts it after every number and treats it as
  equal to itself, and `Float.equals(NaN, NaN)` is true.
- `round(x, digits)` rounds half away from zero; `toFixed` gives text with
  exactly that many digits.
