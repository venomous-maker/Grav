# String

`import "std/types"` (included in `import "std"`) · namespace `std.types`

`String` makes [`Str`](../text/string.md)'s text functions methods of any string
(`s.trim()` is `String.trim(s)` is `Str.trim(s)`), and adds conversions to
numbers and other types, characters (UTF-8 aware), and natural order.

```grav
import "std"

fn main() {
    let s = "  Hello, World  "
    print(s.trim().lower())
    print("user_name".toCamelCase() + " " + "grav".reverse() + " " + "ab".padLeft(4, "."))
    print("${"42".toInt() + 1} ${"19.99".toDecimal() * 3} ${"né".charCount()} ${"né".length}")
    print("{0} has {1} stars".format(["grav", 42]))
    let files: Array<string> = ["file10", "file2", "file1"]
    files.sortBy(String.compareNatural)
    print(files)
}
```

Output:

```text
hello, world
userName varg ..ab
43 59.97 2 3
grav has 42 stars
["file1", "file2", "file10"]
```

- `s.length` counts bytes; `charCount()` counts characters, and `chars()`
  splits into them.
- `"42" as int`, `"2.5" as float`, `"yes" as bool` and `"19.99" as Decimal`
  convert like `toInt()` and the rest, with a `ValueError` for text that is
  not one.
