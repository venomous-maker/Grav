# Null

`import "std/types"` (included in `import "std"`) · namespace `std.types`

`Null`'s methods are the methods of any value that may be null (`T?`): a
default, a check, or an error when it is missing. See
[Null safety](../../learn/09-null-safety.md) for `T?` itself.

```grav
import "std"

fn main() {
    let port: int? = null
    let id: long? = 7
    print("${port.orElse(8080)} ${port.isNull()} ${id.hasValue()} ${id.require("no id")}")
    try { print(port.require("no port given")) } catch (e: ValueError) { print(e.message()) }
}
```

Output:

```text
8080 true true 7
no port given
```
