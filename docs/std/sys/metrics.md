# metrics

`import "std/sys"` (included in `import "std"`) · namespace `std.sys`

Application metrics written in the Prometheus text format for a `/metrics` endpoint:
counters, gauges and histograms (optionally with labels), plus the process's own
memory, CPU time, threads, open files and cycle-collector backlog.

```grav
import "std"

fn main() {
    let m = new MetricsRegistry()
    let requests = m.counterVec("http_requests_total", "HTTP requests.", ["method", "status"])
    let inFlight = m.gauge("http_in_flight", "Requests being handled.")
    let latency = m.histogram("http_request_seconds", "Request time.", [0.05, 0.1, 0.5])

    requests.labels("GET", "200").inc()
    requests.labels("GET", "200").inc()
    requests.labels("POST", "201").inc()
    inFlight.inc()
    for (s in [0.02, 0.07, 0.3, 0.9]) { latency.observe(s) }

    print(m.prometheus())
    print("p50 ≈ ${latency.percentile(0.5)}")
}
```

Output:

```text

# TYPE http_requests_total counter

http_requests_total{method="POST",status="201"} 1
# HELP http_in_flight Requests being handled.
# TYPE http_in_flight gauge
http_in_flight 1
# HELP http_request_seconds Request time.
# TYPE http_request_seconds histogram
http_request_seconds_bucket{le="0.05"} 1
http_request_seconds_bucket{le="0.1"} 2
http_request_seconds_bucket{le="0.5"} 3
http_request_seconds_bucket{le="+Inf"} 4
http_request_seconds_sum 1.29
http_request_seconds_count 4

```

- **Counters** only go up: `inc()`, `add(n)`. **Gauges** go both ways: `set`, `add`,
  `inc`, `dec`, `setToNow()`. `gaugeFunc(name, help, fn)` reads its value from a
  function each time metrics are written (queue lengths, pool sizes).
- **Histograms** count values into buckets by upper bound (Prometheus' default buckets,
  5 ms to 10 s, unless you give your own; `linearBuckets` and `exponentialBuckets` make
  them). `observe(v)`, `time(body)`, or `startTimer()` and `observeSince(t)` record
  seconds. `percentile(q)` estimates a quantile the way Prometheus'
  `histogram_quantile` does.
- **Labels**: `counterVec`, `gaugeVec` and `histogramVec` take label names. Then
  `labels("GET", "200")` is the child for those values, made the first time it is
  asked for. Keep a child you use on a hot path: `labels()` takes a lock, and
  updating a child does not.
- **Process metrics**: `processMetrics()` adds `process_resident_memory_bytes`,
  `process_virtual_memory_bytes`, `process_max_resident_memory_bytes`,
  `process_cpu_seconds_total`, `process_threads`, `process_open_fds`,
  `process_max_fds`, `process_start_time_seconds` and `grav_gc_pending_roots`, all read
  when written. `Metrics.cpuSeconds()`, `Metrics.threads()`, `Metrics.openFiles()` and
  `Metrics.residentBytes()` read them directly.
- **Serving**: `prometheus()` is the text. `MetricsRegistry.contentType()` is the header
  to send with it. `Metrics.global()` is a registry the whole program can share.
- Updates are lock-free atomics. A counter add is one atomic instruction. A histogram
  observe is a binary search over the buckets plus three atomic adds. Both are cheap
  enough for every request.

### class MetricHistogram

How values are spread (request times, sizes): counts in buckets by upper bound, a sum
and a count.

**Constructors**

- `new MetricHistogram(bounds: Array<double>)`

**Static members**

- `static fn defaultBuckets() -> Array<double>` — Prometheus' default buckets: 5 ms to 10 s.
- `static fn exponentialBuckets(start: double, factor: double, count: int) -> Array<double>` — `count` buckets from `start`, each `factor` times the last.
- `static fn linearBuckets(start: double, width: double, count: int) -> Array<double>` — `count` buckets from `start`, `width` apart.

**Fields**

- `bounds: Array<double>` — The bucket upper bounds, rising (+Inf is implied).

**Methods**

- `fn observe(x: double)` — Records one value.
- `fn startTimer() -> long` — A start time for observeSince.
- `fn observeSince(startNs: long)` — Records the seconds since startTimer().
- `fn time(body: fn())` — Runs body and records how long it took, in seconds.
- `fn count() -> long`
- `fn sum() -> double`
- `fn bucket(i: int) -> long` — Values in bucket i alone (above bounds[i - 1], at or under bounds[i]).
- `fn cumulative(i: int) -> long` — Values at or under bounds[i] (cumulative, as Prometheus reports them); i == the number of bounds is +Inf, every value.
- `fn percentile(q: double) -> double` — An estimate of the q-quantile (0.5 the median, 0.99 the 99th percentile), interpolated within its bucket as Prometheus' histogram_quantile does.
