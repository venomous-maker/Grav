# DateTime

`import "std/sys"` (included in `import "std"`) · namespace `std.sys`

Calendar dates and times in the local time zone. A `DateTime` is a moment, stored
as Unix seconds; its parts (year, month, day, hour, ...) are computed in local
time. Values cannot change: `addDays` and friends return a new `DateTime`.

```grav
import "std"

fn main() {
    let d = DateTime.of(2024, 2, 28, 9, 30, 0)
    print(d)
    print(d.addDays(1).date())
    print(d.addDays(2).date())
    print(DateTime.isLeapYear(2024))
    print(DateTime.daysInMonth(2023, 2))
    print(d.weekday())                       // 1 = Monday ... 7 = Sunday
    print(d.dayOfYear())
    print(d.format("%d/%m/%Y %H:%M"))
    let start = DateTime.of(2024, 1, 1)
    print(start.daysUntil(DateTime.of(2024, 12, 25)))
    print(start < d)
}
```


- `DateTime.now()` is the current moment; `fromUnix(seconds)` and `unix()`
  convert to and from Unix time.
- `format` takes C `strftime` patterns: `%Y` year, `%m` month, `%d` day, `%H`
  hour, `%M` minute, `%S` second, `%A` weekday name, `%B` month name, and more.
- `date()` is `YYYY-MM-DD`, `time()` is `HH:MM:SS`, and `print` shows both.
- `==`, `<`, `>` and the rest compare moments.
