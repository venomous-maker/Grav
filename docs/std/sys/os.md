# OS

`import "std/sys"` (included in `import "std"`) · namespace `std.sys`

Questions about the operating system and the environment the program runs in.

```grav
import "std"

fn main() {
    print(OS.platform() != "")
    print(OS.cpuCount() >= 1)
    print(OS.getEnvOr("SURELY_NOT_SET_GRAV", "fallback"))
    OS.setEnv("GRAV_DEMO", "1")
    print(OS.hasEnv("GRAV_DEMO"))
    print(env("GRAV_DEMO"))
    OS.unsetEnv("GRAV_DEMO")
    print(OS.hasEnv("GRAV_DEMO"))
}
```

Output:

```text
true
true
fallback
true
1
false
```

| Function | Gives |
|----------|-------|
| `platform()`, `arch()`, `kernel()` | e.g. `"linux"`, `"x86_64"`, the kernel version |
| `hostname()`, `user()`, `home()` | the machine name, the user name, the home directory |
| `cwd()`, `chdir(path)` | the working directory, and changing it |
| `pid()`, `ppid()` | this process's id and its parent's |
| `cpuCount()`, `pageSize()` | online CPU cores, the memory page size |
| `getEnv`, `getEnvOr`, `hasEnv`, `setEnv`, `unsetEnv` | environment variables (`getEnv` gives `""` when unset) |
| `isTerminal()` | whether standard output is a terminal |
