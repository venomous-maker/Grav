# Time and Stopwatch

`import "std/sys"` (included in `import "std"`) · namespace `std.sys`

Clocks and timing. There are two kinds of clock:

- **Wall-clock time** (`Time.now()`, `Time.nowMs()`): seconds or milliseconds
  since 1 January 1970 UTC. Use it for timestamps. It can jump when the system
  clock is adjusted.
- **Monotonic time** (`Time.monotonicMs()`, `monotonicNs()`): only ever moves
  forward. Use it to measure how long something takes.

A `Stopwatch` measures elapsed time on the monotonic clock.

```grav
import "std"

fn main() {
    let sw = new Stopwatch()
    Time.sleepMs(20)
    let ms = sw.elapsedMs()
    print(ms >= 20 && ms < 1000)
    sw.reset()
    print(sw.elapsedMs() < 20)
    print(Time.now() > 1700000000)
    print(Time.nowMs() / 1000 >= Time.now() - 1)
}
```

Output:

```text
true
true
true
true
```

For calendar dates and formatting, see [`DateTime`](datetime.md).

### class Time

**Static members**

- `static fn now() -> long` — unix seconds
- `static fn nowMs() -> long` — Milliseconds since 1970-01-01 00:00 UTC (wall clock).
- `static fn monotonicMs() -> long` — Milliseconds on a clock that never goes back (for measuring durations).
- `static fn monotonicNs() -> long` — Nanoseconds on a clock that never goes back.
- `static fn sleepMs(ms: long)` — Pauses the calling thread for `ms` milliseconds.

### class Stopwatch

**Constructors**

- `new Stopwatch()`

**Methods**

- `fn reset()` — Starts measuring again from now.
- `fn elapsedNs() -> long` — Nanoseconds since the stopwatch was created or reset.
- `fn elapsedMs() -> long` — Milliseconds since the stopwatch was created or reset.
- `fn elapsedSeconds() -> double` — Seconds since the stopwatch was created or reset.
