# Time and Stopwatch

`import "std/sys"` (included in `import "std"`) · namespace `std.sys`

Clocks and timing. There are two kinds of clock:

- **Wall-clock time** (`Time.now()`, `Time.nowMs()`): seconds or milliseconds
  since 1 January 1970 UTC. Use it for timestamps. It can jump when the system
  clock is adjusted.
- **Monotonic time** (`Time.monotonicMs()`, `monotonicNs()`): only ever moves
  forward. Use it to measure how long something takes.

A `Stopwatch` measures elapsed time on the monotonic clock.

```grav
import "std"

fn main() {
    let sw = new Stopwatch()
    Time.sleepMs(20)
    let ms = sw.elapsedMs()
    print(ms >= 20 && ms < 1000)
    sw.reset()
    print(sw.elapsedMs() < 20)
    print(Time.now() > 1700000000)
    print(Time.nowMs() / 1000 >= Time.now() - 1)
}
```

Output:

```text
true
true
true
true
```

For calendar dates and formatting, see [`DateTime`](datetime.md).

## Duration

A `Duration` is a length of time. It prints compactly, parses the same notation,
and supports `+`, `-`, `*` and comparisons:

```grav
import "std"

fn main() {
    let timeout = Duration.parse("1m30s")
    print(timeout.seconds())
    print(timeout + Duration.ofSeconds(45))
    print(Duration.ofMinutes(150))
    print(Duration.ofMinutes(2) < timeout * 2)
    let sw = new Stopwatch()
    print(sw.elapsed() < Duration.ofSeconds(1))
}
```

Output:

```text
90
2m15s
2h30m
true
true
```

`Duration.parse` accepts `d`, `h`, `m`, `s` and `ms` units (`"2d 3h"`,
`"250ms"`) and throws `ValueError` for anything else.
