# Process

`import "std/sys"` (included in `import "std"`) · namespace `std.sys`

Quick ways to run a shell command line, and information about the current
process. The command goes through `/bin/sh`, so pipes and redirections work, and
so does everything else the shell does with the text. Never build the command
line from untrusted input; use [`Command`](command.md) for that, which passes
arguments without a shell.

```grav
import "std"

fn main() {
    let r = Process.run("echo hello | tr a-z A-Z")
    print(r.ok())
    print(Str.trim(r.output))
    print(Process.exec("exit 4"))
    print(Str.trim(Process.execOutput("printf 'a\\nb\\n' | wc -l")))
    print(Process.pid() > 0)
}
```

Output:

```text
true
HELLO
4
2
true
```

- `run(cmd)` returns a `ProcessResult` with the exit `code` and the standard `output` (standard error still goes to the terminal).
- `exec(cmd)` returns only the exit code, with the output going to your terminal.
- `execOutput(cmd)` returns only the output.
- `args()` is the command line as an `Array<string>`; `sleepMs`, `exit` and `pid`
  do what their names say.
- `executable()` is the running program's absolute path (from `/proc/self/exe` on
  Linux, the loader on macOS), whatever directory it was started from: to start
  more copies of itself as workers with [Command](command.md), or to find files
  installed beside it.

## Shutting down cleanly

`Process.onShutdown(handler)` runs `handler` when the program is asked to stop
(SIGTERM from a process manager or `kill`, SIGINT from Ctrl+C), so a server or
worker can finish the request or job in hand, then exit. `Process.onSignal(sig,
handler)` does the same for any signal (SIGHUP to reload, SIGUSR1). Handlers run
as ordinary code on a thread of their own: the signal handler itself only writes
the signal's number to a pipe. A second SIGINT or SIGTERM while the first is
being handled ends the program at once, so a stuck shutdown can still be
stopped. (`trapSignals` and `signalReceived` remain for programs that would
rather ask between units of work.)

```grav
import "std"

fn main() {
    let jobs = new AtomicInt(0)
    Process.onShutdown(fn() {
        print("stopping after ${jobs.get()} jobs")
        Process.exit(0)
    })
    for (i in 0..3) { jobs.add(1) }
    Process.kill(Process.pid(), Process.SIGTERM())
    Thread.sleepMs(2000)
}
```

Output:

```text
stopping after 3 jobs
```
