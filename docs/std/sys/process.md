# Process

`import "std/sys"` (included in `import "std"`) · namespace `std.sys`

Quick ways to run a shell command line, and information about the current
process. The command goes through `/bin/sh`, so pipes and redirections work, and
so does everything else the shell does with the text. Never build the command
line from untrusted input; use [`Command`](command.md) for that, which passes
arguments without a shell.

```grav
import "std"

fn main() {
    let r = Process.run("echo hello | tr a-z A-Z")
    print(r.ok())
    print(Str.trim(r.output))
    print(Process.exec("exit 4"))
    print(Str.trim(Process.execOutput("printf 'a\\nb\\n' | wc -l")))
    print(Process.pid() > 0)
}
```

Output:

```text
true
HELLO
4
2
true
```

- `run(cmd)` returns a `ProcessResult` with the exit `code` and the standard `output` (standard error still goes to the terminal).
- `exec(cmd)` returns only the exit code, with the output going to your terminal.
- `execOutput(cmd)` returns only the output.
- `args()` is the command line as an `Array<string>`; `sleepMs`, `exit` and `pid`
  do what their names say.
