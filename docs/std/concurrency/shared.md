# Shared

`import "std/concurrency"` (included in `import "std"`) · namespace `std.concurrency`

State shared between threads without one lock in front of everything.

- **`ThreadLocal<T>`**: a value per thread, made by its `init` the first time a
  thread asks. Each thread keeps its values in its own memory, so `get` and
  `set` take no lock: about 30 ns on one thread, and still that with many at
  once, where a map behind a lock slows as threads queue for it. A thread's
  values are let go when it exits.
- **`ConcurrentMap<K, V>`**: a map in 16 shards, each with its own lock, so
  threads on different keys seldom wait for each other. `merge` and
  `computeIfAbsent` read and write a key in one step. Only `size`, `keys` and
  `clear` visit every shard.
- `AtomicLong` and `AtomicBool` are in [async](async.md).

```grav
import "std"

fn main() {
    let scratch = new ThreadLocal<StringBuilder>(fn() -> StringBuilder { return new StringBuilder() })
    let hits = new ConcurrentMap<string, long>()
    let threads = new Array<Thread>()
    for (t in 0..4) {
        threads.push(Thread.spawn(fn() {
            for (i in 0..100) {
                scratch.get().append("x")                       // this thread's own builder
                hits.merge(i % 2 == 0 ? "even" : "odd", 1, fn(a: long, b: long) -> long { return a + b })
            }
        }))
    }
    for (th in threads) { th.join() }
    print("${hits.get("even")} ${hits.get("odd")} ${scratch.get().length()}")
}
```

Output:

```text
200 200 0
```

### class ThreadLocal<T>

A value per thread: the first get() on a thread makes it with `init`.
Each thread keeps its values in its own memory, so get and set take no
lock; a thread's values are let go when it exits.

**Constructors**

- `new ThreadLocal(init: fn() -> T)`

**Methods**

- `fn get() -> T` — This thread's value (made by `init` the first time).
- `fn set(v: T)` — Sets this thread's value.
- `fn has() -> bool` — Whether this thread has a value yet.
- `fn remove()` — Forgets this thread's value (the next get() makes a new one).

### class ConcurrentMap<K, V>

A thread-safe map in 16 shards, each a HashMap with its own lock: threads
on different keys seldom wait for each other, and nothing ever locks the
whole map but size(), keys() and clear().

**Constructors**

- `new ConcurrentMap()`

**Methods**

- `fn get(key: K) -> V`
- `fn getOr(key: K, fallback: V) -> V` — The value for `key`, or `fallback`.
- `fn put(key: K, value: V)`
- `fn containsKey(key: K) -> bool`
- `fn remove(key: K) -> bool` — Removes `key`; whether it was there.
- `fn computeIfAbsent(key: K, make: fn(K) -> V) -> V` — The value for `key`, made by `make` (once, under the key's lock) when missing.
- `fn merge(key: K, value: V, combine: fn(V, V) -> V) -> V` — Puts `value`, or combines it with the value there (`combine(old, value)`); the result.
- `fn size() -> int`
- `fn isEmpty() -> bool`
- `fn keys() -> Array<K>` — The keys at this moment (a copy).
- `fn clear()`
