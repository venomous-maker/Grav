# SMTP

`import "std/net"` (not included in `import "std"`) · namespace `std.net`

`SmtpClient` sends email through a mail server; `EmailMessage` builds the
message, with a text and/or HTML body and attachments.

```grav
import "std"
import "std/net"

fn main() {
    let mail = new EmailMessage()
        .from("Ada <ada@example.com>")
        .to("bob@example.com")
        .cc("Cy <cy@example.com>")
        .subject("Quarterly numbers")
        .text("See the attachment.")
        .attach("q3.csv", "text/csv", Bytes.fromString("month,total\nJul,12\n"))
    print(mail.allRecipients())
    let mime = mail.toMime()
    print(Str.contains(mime, "Subject: Quarterly numbers"))
    print(Str.contains(mime, "multipart/mixed"))
    print(EmailMessage.encodeHeader("Grüße"))
    // new SmtpClient("smtp.example.com", 587).login(user, password).send(mail)
}
```

Output:

```text
["bob@example.com", "cy@example.com"]
true
true
=?UTF-8?B?R3LDvMOfZQ==?=
```

- **The message:** `from`, `to`, `cc`, `bcc` (envelope only, never shown),
  `replyTo`, `subject`, `text`, `html` (sent as alternatives when both are set),
  `header(name, value)` and `attach(filename, type, data)`. `toMime()` gives the
  message as sent: UTF-8 bodies in base64, a `Date` and a `Message-ID`, and
  non-ASCII subjects as encoded words.
- **Sending:** `new SmtpClient(host, port)`, then `login(user, password)` if the
  server needs it, then `send(message)`. Port 587 upgrades to TLS with STARTTLS
  (and refuses to go on without it), port 465 uses TLS from the start; other ports
  use STARTTLS when offered. `withSecurity("none")` is for local test servers,
  `withTls(ctx)` changes which certificates are trusted.
- Logging in tries AUTH PLAIN, then LOGIN. A refusal at any step throws
  `NetError` with the server's reply (credentials are never included in it).

**Fields**

- `timeoutMs: int` — Give up on a silent server after this long.

- `fn withTls(ctx: TlsContext) -> SmtpClient` — Uses these TLS settings; returns this client.
- `fn send(message: EmailMessage)` — Sends `message` to all its recipients in one session.
