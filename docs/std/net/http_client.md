# HTTP client

`import "std/net"` (not included in `import "std"`) · namespace `std.net`

`HttpClient` sends HTTP/1.1 requests to `http://` and `https://` URLs. It keeps
connections open and reuses them for the next request to the same server, so a
client that is kept around is much faster than a new one per request; one client
can be shared by many threads.

```grav
import "std"
import "std/net"

fn main() {
    let app = new HttpServer()
    app.get("/whoami", fn(req: HttpRequest) => HttpResponse.text("token " + req.bearerToken()))
    app.post("/login", fn(req: HttpRequest) => HttpResponse.text("ok").setCookie("sid", "42"))
    app.get("/session", fn(req: HttpRequest) => HttpResponse.text("sid " + req.cookie("sid")))
    app.get("/old", fn(req: HttpRequest) => HttpResponse.redirect("/session", 301))
    app.start(0)
    let base = app.baseUrl()

    let api = new HttpClient().setBearerToken("abc").useCookies(true)
    print(api.get(base + "/whoami").body())
    api.post(base + "/login", "", "")
    print(api.get(base + "/old").body())             // redirected, with the cookie
    for (i in 0..10) { api.get(base + "/whoami") }
    print("idle connections: ${api.idleConnections()}")
    api.close()
    app.stop()
}
```

Output:

```text
token abc
sid 42
idle connections: 1
```

- **Methods:** `get`, `head`, `options`, `delete`, `post`, `put`, `patch`, the
  JSON forms `postJson`, `putJson`, `patchJson`, `getJson` and `getText` (both
  throw on a non-2xx status), `postForm(fields)` / `postForm(formData)` (multipart
  when it has files), `download(url, path)`, and the general
  `send(method, url, body, contentType, headers)`.
- **Responses** of any status are returned (check `ok()` or call `ensureOk()`);
  network failures throw `NetError`, slow servers `TimeoutError` after
  `timeoutMs`. `elapsedMs` says how long the request took.
- **Settings:** default `headers`, `setBasicAuth(user, pw)` or credentials in the
  URL (`http://user:pw@host/`), `setBearerToken(token)`, `useCookies(true)` for a
  browser-like session, `maxRedirects` (0 to see redirects yourself),
  `keepAlive`, `maxIdlePerHost`, `maxResponseBytes`.
- **HTTPS** verifies the server's certificate against the system's trusted
  authorities and its host name. `withTls(ctx)` changes what is trusted, for
  example `TlsContext.client().trustPem(pem)` for a private CA or a self-signed
  test server.
- **Redirects:** 301/302/303 turn a POST into a GET, 307/308 repeat the request
  with its body. Credentials are dropped when a redirect leads to another server.
- `HttpClient.fetch(url)` is a one-off GET; `close()` closes pooled connections.

**Fields**

- `timeoutMs: int` — Give up on connecting or waiting for data after this long (0 = never).
- `headers: Headers` — Sent with every request.
- `maxRedirects: int` — Follow 301/302/303/307/308 redirects up to this many times (0 = never).
- `keepAlive: bool` — Reuse connections between requests (on by default).
- `maxIdlePerHost: int` — Idle connections kept per server.
- `maxResponseBytes: int` — Responses larger than this many bytes throw NetError.
- `tls: TlsContext` — The TLS settings for https:// (null: verify against the system's CAs).
