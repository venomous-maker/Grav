# HTTP

`import "std/net"` (not included in `import "std"`) · namespace `std.net`

An HTTP/1.1 server and client (plain HTTP; TLS is not supported yet).

- **`HttpServer`** routes requests by method and path to handler functions. Each
  connection is served on its own thread, with keep-alive.
- **`HttpClient`** sends requests and follows redirects.
- **`HttpRequest`**, **`HttpResponse`**, **`Headers`** and **`Url`** are the
  pieces in between.

```grav
import "std"
import "std/net"

fn main() {
    let app = new HttpServer()
    app.get("/hello/:name", fn(req: HttpRequest) => HttpResponse.text("hello " + req.param("name")))
    app.get("/search", fn(req: HttpRequest) => HttpResponse.json(
        Json.object().set("q", req.query("q")).set("page", req.query("page"))))
    app.post("/sum", fn(req: HttpRequest) -> HttpResponse {
        let total: long = 0
        for (n in req.json()["numbers"].asArray()) { total += n.asLong() }
        return HttpResponse.json(Json.object().set("total", total))
    })
    app.start(0)                      // serve in the background, on any free port
    let base = "http://127.0.0.1:${app.port()}"

    let http = new HttpClient()
    print(http.get(base + "/hello/grav").body())
    print(http.get(base + "/search?q=json%20parser&page=2").body())
    let r = http.postJson(base + "/sum", Json.parse("{\"numbers\": [1, 2, 39]}"))
    print("${r.status} ${r.json()["total"].asInt()}")
    print(http.get(base + "/missing").status)
    app.stop()
}
```

Output:

```text
hello grav
{"q":"json parser","page":"2"}
200 42
404
```

## The server

- **Routes:** `get`, `post`, `put`, `patch`, `delete` and `any` register a handler
  for a path. `:name` in a path captures one segment (`req.param("name")`), and a
  trailing `*` captures the rest. Unknown paths get 404, known paths with the wrong
  method 405.
- **Middleware:** `use(f)` runs `f` before every handler; return a response to
  answer early, or `null` to continue. `logRequests(true)` prints one line per request.
- **Running:** `listen(port)` serves on the current thread until `stop()` is
  called; `start(port)` serves in the background and `stop()` shuts the server down. Port
  0 picks a free port; `port()` says which.
- **Failures:** when a handler throws, the client gets a 500 response and the
  server carries on. Each request is also a panic recovery point: a panicking
  handler answers 500, the panic is logged to standard error, and the server keeps
  serving. `withPanicRecovery(false)` turns that off for the server.

## Requests and responses

- `HttpRequest` has `method`, `path`, `param(name)`, `query(name)`,
  `header(name)`, `body()`, `json()` and `form()`.
- `HttpResponse` is built with `text(s)`, `html(s)`, `json(value)`,
  `of(status, contentType, body)`, `status(code)`, `notFound()`,
  `badRequest(message)` and `redirect(url)`, then adjusted with `.header(k, v)`
  and `.withStatus(code)`.

## The client

`HttpClient` has `get`, `post`, `put`, `delete`, `postJson`, `postForm` and the
general `request`. Set its `timeoutMs` and default `headers`. Responses have
`status`, `ok()` (a 2xx status), `body()`, `json()` and `getHeader(name)`.
`HttpClient.fetch(url)` is a one-line GET with default settings. Network failures
throw `NetError`.

`Url.parse`, `Url.encode`, `Url.decode` and `Url.parseQuery` handle URLs.

See also [`WebSocket`](websocket.md), which shares the server's port, and
[`examples/20_networking.grav`](../../../examples/20_networking.grav) for a REST
API and a chat room in one program.
