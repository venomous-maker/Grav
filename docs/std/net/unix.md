# Unix sockets

`import "std/net"` (not included in `import "std"`) · namespace `std.net`

A Unix domain socket connects programs on the same machine through a file path.
It is faster than TCP over `localhost`, and file permissions decide who may
connect. The streams and listeners are the [TCP classes](tcp.md), so
`readLine`, `write` and the rest work the same.

```grav
import "std"
import "std/net"

fn main() {
    let path = "/tmp/grav-doc-${Process.pid()}.sock"
    let listener = UnixSocket.listen(path)
    let server = Thread.spawn(fn() {
        let c = listener.accept()
        c.lines(fn(line: string) { c.writeLine(Str.upper(line)) })
        c.close()
    })
    let c = UnixSocket.connect(path)
    c.writeLine("local only")
    print(c.readLine())
    c.shutdownWrite()
    server.join()
    c.close()
    UnixSocket.remove(listener, path)
    print(new File(path).exists())
}
```

Output:

```text
LOCAL ONLY
false
```

- `UnixSocket.listen(path)` creates the socket file, replacing a socket left by
  an earlier run (but never another kind of file); `UnixSocket.remove(listener,
  path)` closes the listener and deletes the file.
- `UnixSocket.connect(path)` throws `NetError` when nothing listens there.
- Paths are limited to about 100 bytes by the system.
