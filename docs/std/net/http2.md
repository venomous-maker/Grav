# HTTP/2

`import "std/net"` · namespace `std.net`

An HTTP/2 client (RFC 9113): one connection carries many requests at once, with
headers compressed by HPACK (RFC 7541).

```text
import "std"
import "std/net"

fn main() {
    let h2 = Http2Client.open("https://example.com")        // TLS; "h2" agreed by ALPN
    let res = h2.get("/api/items")
    print("${res.status} ${res.header("content-type")}")
    print(res.text())

    // twenty requests in flight at once, on the one connection
    let reqs = new Array<Http2Request>()
    for (i in 0..20) { reqs.push(Http2Request.get("/api/items/${i}")) }
    for (r in h2.requestAll(reqs)) { print("${r.stream}: ${r.status}") }

    let saved = h2.post("/api/items", "{\"name\": \"pen\"}")
    h2.close()
}
```

- **Connecting.** `Http2Client.open("https://host[:port]")` connects with TLS and
  offers `h2` by ALPN (a NetError if the server will not speak it);
  `"http://host[:port]"` speaks HTTP/2 in the clear with prior knowledge (h2c).
  Pass a `TlsContext` to trust other certificates (`TlsContext.insecureClient()`
  for a test server).
- **Requests.** `get`, `post` and `request(Http2Request)` send one and wait for its
  answer; `requestAll` sends many at once (as many as the server allows in
  flight, the rest as streams finish) and gives the answers in the requests'
  order. A `Http2Response` has the `status`, the `headers` (lower-case names), the
  `body` as `Bytes`, `text()` and the `stream` it came on.
- **The protocol.** Flow control both ways (large uploads wait for the server's
  window; downloads open it as they are read), CONTINUATION frames, padding,
  1xx answers skipped, PINGs answered, the server's settings honoured. A
  RST_STREAM fails its request, a GOAWAY the requests it did not take, with a
  `NetError` naming the server's reason.
- **Checked** against nginx and Python's `h2`, with HPACK's tables generated from
  the RFC's (`tools/gen-hpack.py`). A client is for one thread.
