# IO

`import "std/io"` (included in `import "std"`) · namespace `std.io`

Console input and output beyond the built-in `print` and `input`: printing
without a line break, printing to standard error, and reading typed values.
The most used helpers are also available as plain functions: `printRaw`,
`eprint`, `readLine`, `prompt`, `readInt`.

```grav
import "std"

fn main() {
    printRaw("no line break, ")
    IO.write(42)
    print("")
    IO.eprint("this goes to standard error")
    let name = readLine()                  // "" at the end of input
    print("[${name}]")
}
```

Output:

```text
no line break, 42
[]
```

| Function | Does |
|----------|------|
| `IO.print(x)`, `print(x)` | writes a value and a line break |
| `IO.write(x)`, `printRaw(s)` | writes without a line break |
| `IO.eprint(x)`, `eprint(s)` | writes a line to standard error |
| `IO.flush()` | sends buffered output now |
| `IO.readLine()`, `readLine()`, `input()` | one line, without its line break; `""` at the end |
| `IO.prompt(msg)`, `prompt(msg)` | writes `msg`, then reads a line |
| `IO.readInt()`, `readFloat()`, `readBool()` ... | reads a line and converts it; `ValueError` when it is not a number ([`Format`](../text/convert.md)) |
| `IO.promptInt(msg)`, `IO.promptFloat(msg)` | writes `msg`, then reads the answer as a number |
| `IO.readAll()`, `IO.readLines()` | everything left on standard input |

Standard output is buffered when it is not a terminal; it is flushed before
anything is written to standard error and when the program ends.
