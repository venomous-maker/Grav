# Term

`import "std/io"` (included in `import "std"`) · namespace `std.io`

Terminal styling with ANSI escape codes (colours, bold, underline), cursor
control, and the terminal's size. Each style function wraps a string in the codes
that switch the style on and back off, so styles can be nested and mixed with plain
text.

```grav
import "std"

fn main() {
    print(Term.bold("Build report"))
    print("${Term.green("ok")}   parser")
    print("${Term.red("FAIL")} codegen")
    print(Term.style("custom", "4;35"))
    print(Term.rgb("orange", 255, 165, 0))
}
```

- Colours: `red`, `green`, `yellow`, `blue`, `magenta`, `cyan`, `gray`, `white`;
  `color(s, n)` and `background(s, n)` use the 256-colour palette; `rgb` and
  `bgRgb` use true colour.
- Styles: `bold`, `dim`, `italic`, `underline`, `inverse`, `strike`, or any SGR
  code with `style(s, "code")`.
- Screen: `clear()`, `clearLine()`, `moveTo(row, col)`, `hideCursor()`,
  `showCursor()`, and `width()` / `height()` of the terminal.

The codes are written whether or not the output is a terminal, so leave styling
out when writing to files or pipes.
