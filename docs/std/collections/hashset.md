# HashSet

`import "std/collections"` (included in `import "std"`) · namespace `std.collections`

`HashSet<T>` holds each value at most once, with O(1) average `add`, `contains`
and `remove`. Elements can be any type `HashMap` accepts as a key. Iteration
order is not defined; use [`Set`](set.md) to keep insertion order.

```grav
import "std"

fn main() {
    let a: HashSet<int> = [1, 2, 3, 4]
    let b: HashSet<int> = [3, 4, 5]
    print(a.add(2))                  // already there
    print(a.contains(3))
    let both = a.intersect(b).toArray()
    Sort.sort(both)
    print(both)
    let all = a.union(b).toArray()
    Sort.sort(all)
    print(all)
    let onlyA = a.difference(b).toArray()
    Sort.sort(onlyA)
    print(onlyA)
    print(b.isSubsetOf(a))
}
```

Output:

```text
false
true
[3, 4]
[1, 2, 3, 4, 5]
[1, 2]
false
```

`union`, `intersect` and `difference` return new sets.
