# LinkedList

`import "std/collections"` (included in `import "std"`) · namespace `std.collections`

`LinkedList<T>` is a doubly linked list: adding and removing at either end is
O(1), but reaching element `i` walks from the nearer end (O(n)). Prefer `Array`
in general; use a linked list when you mostly add and remove at the ends and
never index. (A `Deque` also does both ends in O(1) and indexes in O(1).)

```grav
import "std"

fn main() {
    let list = new LinkedList<string>()
    list.addLast("b")
    list.addLast("c")
    list.addFirst("a")
    print(list)
    print("${list.first()} ${list.last()} ${list.get(1)}")
    print(list.removeFirst())
    list.reverse()
    print(list)
}
```

Output:

```text
["a", "b", "c"]
a c b
a
["c", "b"]
```

Removing from an empty list throws `StateError`; a bad index throws `IndexError`.
