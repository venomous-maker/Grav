# Deque

`import "std/collections"` (included in `import "std"`) · namespace `std.collections`

`Deque<T>` (a double-ended queue) adds and removes at both ends in O(1), using a
ring buffer. Indexing (`d[i]`, counted from the front) is O(1) too. Use it for
queues, sliding windows, and undo histories with a limit.

```grav
import "std"

fn main() {
    let d = new Deque<int>()
    d.pushBack(2)
    d.pushBack(3)
    d.pushFront(1)
    print(d)
    print("${d.peekFront()} ${d.peekBack()} ${d[1]}")
    print(d.popFront())
    print(d.popBack())
    print(d)

    // a sliding window of the last 3 values
    let window = new Deque<int>()
    for (v in [4, 8, 15, 16, 23]) {
        window.pushBack(v)
        if (window.size() > 3) { window.popFront() }
    }
    print(window)
}
```

Output:

```text
[1, 2, 3]
1 3 2
1
3
[2]
[15, 16, 23]
```

`popFront`, `popBack`, `peekFront` and `peekBack` on an empty deque throw
`StateError`; a bad index throws `IndexError`.
