# List

`import "std/collections"` (included in `import "std"`) · namespace `std.collections`

`List<T>` is an ordered list with collection-style method names (`add`,
`insert`, `removeAt`, `filter` returning a `List`). It is built on `Array<T>` and
behaves the same way; use whichever reads better in your code.

```grav
import "std"

fn main() {
    let todo = new List<string>()
    todo.add("write")
    todo.add("test")
    todo.insert(0, "plan")
    print(todo)
    print("${todo[1]} ${todo.first()} ${todo.size()}")
    todo.remove("test")
    print(todo.contains("test"))
    let long = todo.filter(fn(t) => t.length > 4)
    print(long)
}
```

Output:

```text
["plan", "write", "test"]
write plan 3
false
["write"]
```
