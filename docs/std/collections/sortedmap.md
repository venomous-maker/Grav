# SortedMap

`import "std/collections"` (included in `import "std"`) · namespace `std.collections`

`SortedMap<K, V>` keeps its keys sorted by a comparison function you give it.
Lookups are O(log n) (binary search); inserting and removing are O(n). It answers
questions a plain map cannot: the smallest key, the largest, or every key in a range.

```grav
import "std"

fn main() {
    let scores = new SortedMap<string, int>(fn(a, b) => Str.compare(a, b))
    scores["carol"] = 88
    scores["alice"] = 95
    scores["bob"] = 72
    print(scores.keys())
    print("${scores.firstKey()} ${scores.lastKey()}")
    print(scores.keysBetween("b", "c"))
    scores.forEach(fn(name, s) { print("${name}: ${s}") })

    let byTime = new SortedMap<int, string>(fn(a, b) => a - b)
    byTime[930] = "standup"
    byTime[800] = "coffee"
    byTime[1200] = "lunch"
    print(byTime.values())
}
```

Output:

```text
["alice", "bob", "carol"]
alice carol
["bob"]
alice: 95
bob: 72
carol: 88
["coffee", "standup", "lunch"]
```

`get` with a missing key throws `NotFound`; `firstKey` and `lastKey` on an empty
map throw `IndexError`.
