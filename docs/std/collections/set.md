# Set

`import "std/collections"` (included in `import "std"`) · namespace `std.collections`

`Set<T>` holds each value once and keeps insertion order. Membership is checked
with `==`, so it works for any element type, but `contains` is O(n). For large
sets of numbers or strings, use [`HashSet`](hashset.md).

```grav
import "std"

fn main() {
    let tags = new Set<string>()
    for (t in ["red", "blue", "red", "green", "blue"]) { tags.add(t) }
    print(tags)
    print(tags.size())
    print(tags.get(0))
    let warm = new Set<string>()
    warm.add("red")
    warm.add("orange")
    print(tags.intersect(warm))
    print(tags.union(warm))
}
```

Output:

```text
{"red", "blue", "green"}
3
red
{"red"}
{"red", "blue", "green", "orange"}
```
