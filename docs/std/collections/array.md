# Array

`import "std/collections"` (included in `import "std"`) · namespace `std.collections`

`Array<T>` is the general-purpose list: elements in order, indexed from 0,
growing as you add. It is the collection to reach for first.

- `push`/`add`, `pop`, `get`, `set` and indexing `xs[i]` are O(1) (adding is O(1)
  on average: the buffer doubles when full).
- `insert`, `removeAt` and `remove` move the elements after the position: O(n).
- Every index is checked: an index outside `0..size()` throws `IndexError`.
- `[1, 2, 3]` builds an `Array` wherever one is expected.

```grav
import "std"

fn main() {
    let xs: Array<int> = [5, 3, 8]
    xs.push(1)
    xs.insert(0, 9)
    print(xs)
    print("${xs[0]} ${xs.first()} ${xs.last()} ${xs.size()}")
    xs[1] = 50
    print(xs.removeAt(2))
    print(xs.indexOf(8))
    print(xs.contains(42))
    print(xs[1..3])

    let evens = xs.filter(fn(n) => n % 2 == 0)
    print(evens)
    print(xs.map(fn(n) => n * 2))
    print(xs.reduce(0, fn(sum, n) => sum + n))
    print(xs.mapTo(fn(n) => "#${n}"))
    print(xs.maxBy(fn(a, b) => a - b))

    xs.sortBy(fn(a, b) => a - b)
    print(xs)
    xs.removeWhere(fn(n) => n > 10)
    print(xs)
}
```

Output:

```text
[9, 5, 3, 8, 1]
9 9 1 5
3
2
false
[50, 8]
[50, 8]
[18, 100, 16, 2]
68
["#9", "#50", "#8", "#1"]
50
[1, 8, 9, 50]
[1, 8, 9]
```

Methods that build a new collection (`filter`, `map`, `mapTo`, `slice`, `copy`,
`toArray`) return a copy, so changing the result never changes the original.
`indexOf`, `contains` and `remove` compare with `==` (an object's `operator==`
when it has one). See [Arrays and collections](../../learn/07-arrays-and-collections.md).

### class Array<T>

**Constructors**

- `new Array()`
- `new Array(capacity: int)` — Pre-sized: room for `capacity` elements before the first reallocation.

**Methods**

- `fn reserve(capacity: int)` — Make room for at least `capacity` elements in total.
- `fn size() -> int` — The number of elements.
- `fn length() -> int` — The number of elements (same as size()).
- `fn isEmpty() -> bool` — Whether the array has no elements.
- `fn clear()` — Removes every element.
- `fn get(i: int) -> T` — The element at index i; an index out of range throws IndexError.
- `fn set(i: int, item: T)` — Replaces the element at index i; an index out of range throws IndexError.
- `fn operator[](i: int) -> T` — `xs[i]`: the element at index i (IndexError when out of range).
- `fn operator[]=(i: int, item: T)` — `xs[i] = v`: replaces the element at index i.
- `fn first() -> T` — The first element; an empty array throws IndexError.
- `fn last() -> T` — The last element; an empty array throws IndexError.
- `fn getOr(i: int, fallback: T) -> T` — The element at index i, or `fallback` when i is out of range.
- `fn push(item: T)` — Appends an element at the end (amortized O(1)).
- `fn add(item: T)` — Appends an element at the end (same as push).
- `fn addAll(other: Array<T>)` — Appends every element of another array.
- `fn pop() -> T` — Removes and returns the last element; an empty array throws StateError.
- `fn insert(index: int, item: T)` — Inserts an element before `index` (0..size()); later elements move up.
- `fn removeAt(index: int) -> T` — Removes and returns the element at index; later elements move down.
- `fn remove(item: T) -> bool` — Removes the first element equal to `item`; reports whether one was found.
- `fn removeWhere(pred: fn(T) -> bool) -> int` — Removes every element matching `pred` (keeping order); returns how many.
- `fn swap(i: int, j: int)` — Exchanges the elements at indexes i and j.
- `fn fill(item: T)` — Sets every element to `item`.
- `fn indexOf(item: T) -> int` — The index of the first element equal to `item` (==), or -1.
- `fn lastIndexOf(item: T) -> int` — The index of the last element equal to `item` (==), or -1.
- `fn contains(item: T) -> bool` — Whether some element equals `item` (==).
- `fn reverse()` — Reverses the order of the elements in place.
- `fn copy() -> Array<T>` — A new array with the same elements (a shallow copy).
- `fn toString() -> string` — As text: [1, 2, 3] (strings in quotes).
- `fn toArray() -> Array<T>` — A new array with the same elements (same as copy()).
- `fn slice(start: int, end: int) -> Array<T>` — Elements [start, end) as a new array (bounds are clamped).
- `fn dispose()` — Releases the elements and the buffer now, leaving the array empty.
- `fn forEach(f: fn(T))` — Calls f on each element, in order.
- `fn forEachIndexed(f: fn(int, T))` — Calls f with each index and element, in order.
- `fn map(f: fn(T) -> T) -> Array<T>` — A new array of f(x) for each element x (same element type; see mapTo for another).
- `fn filter(keep: fn(T) -> bool) -> Array<T>` — A new array of the elements for which `keep` returns true.
- `fn reduce(init: T, f: fn(T, T) -> T) -> T` — Combines the elements left to right: f(f(init, x0), x1)...
- `fn any(pred: fn(T) -> bool) -> bool` — Whether `pred` holds for at least one element.
- `fn all(pred: fn(T) -> bool) -> bool` — Whether `pred` holds for every element (true when empty).
- `fn countWhere(pred: fn(T) -> bool) -> int` — How many elements `pred` holds for.
- `fn findIndex(pred: fn(T) -> bool) -> int` — Index of the first element matching `pred`, or -1.
- `fn findFirst(pred: fn(T) -> bool, fallback: T) -> T` — The first element matching `pred`, or `fallback`.
- `fn mapTo<U>(f: fn(T) -> U) -> Array<U>` — Map into another element type.
- `fn fold<A>(init: A, f: fn(A, T) -> A) -> A` — Reduce into an accumulator of any type.
- `fn maxBy(cmp: fn(T, T) -> int) -> T` — The largest element by `cmp` (throws StateError when empty).
- `fn minBy(cmp: fn(T, T) -> int) -> T` — The smallest element by `cmp` (cmp(a, b) < 0 means a is smaller); empty throws IndexError.
- `fn sortBy(cmp: fn(T, T) -> int)` — Stable sort (TimSort, lib/core/timsort.grav): `cmp(a, b)` < 0 puts a first. O(n log n), and close to O(n) on input that is mostly in order.

### Functions

- `fn mapTo<T, U>(xs: Array<T>, f: fn(T) -> U) -> Array<U>` — Free-function forms (kept for compatibility; prefer xs.mapTo(f) / xs.fold(init, f)).
- `fn fold<T, A>(xs: Array<T>, init: A, f: fn(A, T) -> A) -> A` — Folds an array into a value of another type: f(f(init, x0), x1)...
