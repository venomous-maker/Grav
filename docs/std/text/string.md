# Str

`import "std/text"` (included in `import "std"`) · namespace `std.text`

`Str` gathers the string functions as static methods that take the string first:
`Str.trim(s)`, `Str.split(s, ",")`. Strings cannot change, so every function that
"modifies" one returns a new string.

Positions and lengths are in **bytes**, like `s.length` and `s[i]`. For plain
ASCII text that is the same as characters; for other text, see
[What a string is made of](../../learn/03-strings-and-text.md#what-a-string-is-made-of).

```grav
import "std"

fn main() {
    let s = "  Hello, Grav world  "
    let t = Str.trim(s)
    print(t)
    print(Str.upper(t))
    print(Str.contains(t, "Grav"))
    print(Str.indexOf(t, "o"))
    print(Str.lastIndexOf(t, "o"))
    print(Str.startsWith(t, "Hello"))
    print(Str.replace(t, "o", "0"))
    print(Str.split("a,b,,c", ","))
    print(Str.words(t))
    print(Str.join(["x", "y", "z"], "-"))
    print(Str.substring(t, 7, 4))
    print(Str.padLeft("7", 3, "0"))
    print(Str.repeat("ab", 3))
    print(Str.count("banana", "a"))
    print(Str.isDigits("2024"))
    print(Str.compare("apple", "banana") < 0)
    print(Str.capitalize("grav"))
    print(Str.lines("one\ntwo\nthree").size())
}
```

- `indexOf` and friends return `-1` when nothing is found.
- `split` keeps empty pieces; `words` splits on any run of whitespace and drops
  empty ones.
- `substring(s, start, len)` takes a length; `slice(s, start, end)` takes an end
  position, like `s[start..end]`.
- `charAt(s, i)` returns the byte at `i` (`IndexError` when out of range), and
  `fromChar(code)` turns a code point back into a one-character string.
