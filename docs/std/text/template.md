# template

`import "std/text"` (included in `import "std"`) · namespace `std.text`

Mustache templates over JSON data, HTML-escaped by default: pages, e-mails and
messages filled in from a [`JsonValue`](../data/json.md). A template is parsed once
and rendered as often as you like, from any number of threads.

```grav
import "std"

fn main() {
    let t = Template.compile("""
        <h1>Hello {{name}}!</h1>
        <ul>
          {{#items}}
          <li>{{title}}: {{price}}</li>
          {{/items}}
        </ul>
        {{^items}}<p>Nothing yet.</p>{{/items}}
        {{> footer}}
        """).partial("footer", "<footer>{{shop.name}}</footer>")
    let data = Json.parse("{\"name\": \"<Ada>\", \"items\": [{\"title\": \"Tea\", \"price\": 2.5}, {\"title\": \"Cake\", \"price\": 4}], \"shop\": {\"name\": \"Kahawa & Co\"}}")
    print(t.render(data))
    print(Template.compile("Dear {{name}},").raw().render(data))
}
```

Output:

```text
<h1>Hello &lt;Ada&gt;!</h1>
<ul>
  <li>Tea: 2.5</li>
  <li>Cake: 4</li>
</ul>

<footer>Kahawa &amp; Co</footer>
Dear <Ada>,
```

- **Tags**: `{{name}}` (escaped), `{{{name}}}` or `{{& name}}` (as it is), dotted names
  `{{shop.name}}`, `{{.}}` for the current value, `{{#section}}…{{/section}}` (a list
  repeats it; `false`, `null`, a missing value or an empty list skips it; anything else
  is entered as the new context), `{{^inverted}}…{{/inverted}}`, `{{! comments }}`,
  `{{> partial}}`, and `{{=<% %>=}}` to change the delimiters.
- **Lookup** goes from the innermost context outward, so `{{shop.name}}` works inside
  `{{#items}}`.
- **Standalone lines**: a section, comment or partial tag alone on its line takes the
  whole line with it, as the Mustache spec says, so templates can be indented freely.
- **`raw()`** turns escaping off for plain-text output (e-mail bodies, SMS).
- **Errors**: an unclosed section, a mismatched `{{/name}}` or an unclosed tag is a
  `TemplateError` whose message gives the line.
- Numbers print as JSON writes them; `true` and `false` as words; objects and arrays as
  JSON.
