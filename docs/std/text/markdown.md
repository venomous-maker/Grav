# Markdown

`import "std/text"` (included in `import "std"`) · namespace `std.text`

Markdown to HTML (CommonMark's everyday parts and GitHub's tables), and to
plain text: for mail bodies, docs, comments.

```grav
import "std"

fn main() {
    print(Markdown.toHtml("# Hello\n\nThanks for **joining**. See [the docs](https://x.io).\n\n- one\n- two"))
    print(Markdown.toText("Thanks for **joining**. See [the docs](https://x.io)."))
    print(Markdown.toHtml("Hi <script>x()</script> [x](javascript:x())", true))
}
```

Output:

```text
<h1>Hello</h1>
<p>Thanks for <strong>joining</strong>. See <a href="https://x.io">the docs</a>.</p>
<ul>
<li>one</li>
<li>two</li>
</ul>
Thanks for joining. See the docs (https://x.io).
<p>Hi &lt;script&gt;x()&lt;/script&gt; <a href="#">x</a></p>
```

- **Blocks**: ATX (`#`) and setext headings, paragraphs, `>` quotes, `-` `*` `+`
  and `1.` lists (nested by indentation), fenced code (with a language class)
  and indented code, `---` rules, `| tables |` with alignment, and HTML blocks.
- **Inline**: `**strong**`, `*em*` and `_em_`, `~~strike~~`, `` `code` ``,
  `[links](url "title")`, `![images](src)`, `<https://autolinks>`, line breaks
  (two trailing spaces or `\`), and `\` escapes. Text is HTML-escaped.
- **Safe mode** (`toHtml(source, true)`, for anything users write): raw HTML is
  escaped instead of passed through, and links or images to `javascript:`,
  `vbscript:` or `data:` (other than `data:image/`) point to `#`.
- `toText` gives the same text readable without markup (a plain-text mail),
  links written as `text (url)`.
